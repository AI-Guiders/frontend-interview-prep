# Frontend Interview Prep (JS / TS / React)

**Org:** [AI-Guiders](https://github.com/AI-Guiders) · **Format:** self-paced study notes · **Target:** technical screen + machine coding + light frontend system design

Материал для **самостоятельной** подготовки к собесу Frontend Developer. Среда и диалог с ментором не требуются: открыл модуль → прочитал → сделал practice → отметил чеклист.

## Быстрый старт

1. [curriculum/00-MAP.md](curriculum/00-MAP.md) — карта и порядок модулей.
2. Выбери трек ниже и иди **по одному модулю за раз**.
3. После модуля — задачи из [practice/](practice/) и вопросы из [drills/](drills/).
4. Прогресс: [progress/CHECKLIST.md](progress/CHECKLIST.md).
5. Внешние ссылки (дополнение к своему Google research): [sources/CURATED.md](sources/CURATED.md).

## Треки

| Трек | Когда | Ритм |
|------|--------|------|
| **Sprint (~10–14 дней)** | собес скоро | карта → JS async → TS → React model → machine coding → чеклист «must» |
| **Standard (~3–4 недели)** | есть запас | все модули 01–10 + practice pack |
| **Stretch** | Middle+ / Senior FE | + FE system design, perf budgets, a11y deep |

## Структура

| Путь | Содержание |
|------|------------|
| `curriculum/` | Фундамент по слоям |
| `practice/` | Код руками (debounce, Promise.all, UI-виджеты) |
| `drills/` | Банк вопросов «что спросят» |
| `sources/` | Курируемые внешние источники |
| `progress/` | Чеклист готовности |

## Принципы

- Сначала **модель** (как работает), потом trivia API.
- На каждый «правильный» ответ — **trade-off** (когда не так).
- Писать код **вслух / на бумаге / в пустом файле**, не только «читал».
- React 19 / RSC / Compiler — понимать *зачем*, не зубрить changelog.
